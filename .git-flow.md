# FSR3 Mod - Git Flow 配置

## 🎯 当前分支结构

```
master ──┐                    # ✅ 稳定发布版本
    │     release/*           # 发布准备分支
    └ develop *                # 🔧 开发主分支 (当前)
          ├── feature/*       # 新功能开发
          └── bugfix/*        # Bug 修复
```

## 📝 提交规范 (Conventional Commits)

| 类型 | 格式 | 示例 |
|------|------|------|
| **feat** | `feat: ...` | 新功能 → `feat: add zero-copy frame buffer` |
| **fix** | `fix: ...` | Bug 修复 → `fix: prevent game crash on load` |
| **docs** | `docs: ...` | 文档更新 |
| **chore** | `chore: ...` | 维护任务 |

## 🚀 常用命令

### 开发新功能
```bash
# 从 develop 创建功能分支
git checkout -b feature/perf-optimization

# 开发完成后合并回 develop
git checkout develop
git merge --no-ff feature/perf-optimization
```

### 发布新版本
```bash
git checkout develop
git checkout -b release/1.2.0
# ...测试后...
git checkout master
git merge --no-ff release/1.2.0
git tag v1.2.0
git push origin master --tags
```

### 紧急修复 (生产环境)
```bash
git checkout master
git checkout -b hotfix/crash-fix
# ...快速修复后直接合并到 master
git checkout master && git merge --no-ff hotfix/xxx
```

## 📊 状态检查

```bash
git status                     # 查看当前状态
git log --oneline -10          # 最近提交历史
git branch -a                  # 所有分支
git diff origin/master         # 与远程差异
```
